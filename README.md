# Stash

Internal design artifact platform for Weedmaps design team and leadership.

## Getting started

```bash
npm install
npm run dev
```

## Stack

- React 18
- Vite
- Pure CSS / inline styles (no UI framework)

## Features

- **Explore** — masonry grid of design artifacts (images, videos, Figma embeds, URLs)
- **Projects** — organized by folder, with versioned pages per project
- **Upload** — drag & drop files, paste Figma links, or add website URLs
- **Device frames** — mobile content auto-wraps in iPhone shell
- **Lightbox** — full-screen viewer for all artifact types
- **Publish to Feed** — share artifacts team-wide
